# Real vs AI

When asked to prepare image pairs for the game, follow [the Codex image-pair workflow](docs/image-pair-pipeline.md#prepare-a-batch-in-codex). Use the built-in image generation tool and leave the resulting pairs in the admin review queue.

When asked to refresh existing library pairs, use the [library replacement workflow](docs/image-pair-pipeline.md#refresh-existing-library-pairs-in-codex).

Before suggesting Unsplash searches, read [the search suggestion log](docs/unsplash-search-log.md). Avoid repeats and close rephrasings, and append the new suggestions to the log.
